a system we don't yet have access to. Not a general TODO list (that's [PLAN.md](PLAN.md)). An item
lives here only because Claude *can't* resolve it from the repo — it needs an answer from outside.

> When a session touches a related area — or the user mentions an upcoming meeting — surface the
> relevant items proactively. When an answer arrives, move the item to **Resolved** with the answer +
> date.
